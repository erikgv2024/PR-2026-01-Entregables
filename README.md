# La Canchita — Entregables PR 2026 01

Proyecto del curso Arquitectura de Entornos Web.

Repositorio público: https://github.com/erikgv2024/PR-2026-01-Entregables

## Contenido

- `informe/`: informe Word y cuatro PDF de wireframes de alta y baja fidelidad, para computadora y celular.
- `presentacion/`: presentación PowerPoint del proyecto.
- `sitio/`: sitio completo con HTML, CSS, JavaScript, imágenes y video.

Los documentos distinguen los archivos **La Canchita · Alta fidelidad** y **La Canchita · Baja fidelidad** del proyecto de Penpot.

## Consultar el sitio

Abrir `sitio/index.html` en un navegador. Conservar la estructura de carpetas para cargar los recursos.

Web publicada del proyecto: https://erikgv2024.github.io/la-canchita-web/
